## PageTrace 的实际做法

- `index.html` 的普通品牌 header 和月份导航随页面自然滚动，不固定在屏幕顶部。
- 移动端 `.month-date-col` 使用 `position: sticky; top: 0; z-index: 10`，保留一条紧凑的月份分组栏。
- 滚动监听只负责触底加载，没有反复切换顶栏展开/收起的滚动方向状态机。
- Android 的系统状态栏空间由 MainActivity 的 WindowInsets 处理，避免重复占用。

## LightNote 已实现的顶栏设计

1. 顶部展开时显示两行：第一行 LightNote 图标、名称和圆形汉堡按钮，约 52px；第二行当前笔记本或“全部笔记”、数量和排序，48px。
2. 将这两行与卡片放入同一个列表滚动容器；品牌行正常滚动，第二行使用 sticky 吸顶。
3. 向上划动列表后，品牌行逐渐滚出，剩下 48px 的工具栏；回到列表顶部自然恢复两行。
4. 汉堡按钮放在 Logo 行，恢复带边框的 44px 圆形样式；排序按钮保留在第二行。
5. 系统状态栏保持现状；卡片字号和长按菜单不随顶栏收起而缩小。
6. 只改 APK 的笔记列表界面，正文页、网页版和 Windows 客户端不跟随更改。
7. Android 打开正文时保留列表组件及其布局，返回时保留原滚动位置、已显示的卡片和顶栏收起状态；编辑笔记不再重置列表分页。

该设计不需要新的滚动方向判断、云端逻辑或额外展开/收起状态。
