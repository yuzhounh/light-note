# LightNote 更新与开发日志 (Changelog)

### V2.2.1 (2026-09-28)

**版本定位**
聚焦 Web 端列表排版视觉与交互体验打磨。重构笔记卡片第四行元素对齐规范，实现笔记本标签紧随日期时间的基准左对齐与弹性长文本截断；优化悬停置顶与删除按钮的空间预留，彻底杜绝布局抖动；全面移除 Web 端列表卡片缩略图，避免跨端未同步或私有协议造成的图片破损，打造纯粹统一的双行文字摘要流；同步加宽列表主栏至 320px，提供更为舒展的阅读浏览视野。

**主要修改**

* **笔记卡片第四行排版与对齐重构**：
  * 将原先分散在两端的“时间”与“笔记本标签”重组为左侧统一弹性信息流（`flex items-center gap-2 min-w-0 flex-1 mr-2`），所有卡片的笔记本标签统一起始对齐基准线，彻底消除因笔记本名称长短不一导致的右侧锯齿状错乱；
  * 笔记本标签支持自适应截断（`truncate`），最大显示宽度提升至 `140px`，超长名称自动显示省略号 `...` 并支持鼠标悬停浮动查看全称（`title`）；
  * 置顶与删除快捷按钮独立定位于整行最右端（`shrink-0`），默认透明占位（`opacity-0`），鼠标悬停（`group-hover:opacity-100`）平滑显现，既保留操作便捷性，又杜绝鼠标移入时的界面抖动。
* **Web 端卡片缩略图优化与极简纯文本设计**：
  * 彻底移除 Web 端笔记卡片提取图片和渲染缩略图的逻辑，清理冗余的异步图片解析开销；
  * 解决桌面端本地自定义伪协议（`https://lightnote.attachments/`）在浏览器环境无法直达及未开通云端 Storage 时显示破图图标（Broken Image）的缺陷；
  * 统一恢复为规范的标题 + 双行正文摘要卡片流，大幅提升多笔记滚动渲染性能。
* **第二栏（笔记列表栏）视觉空间加宽**：
  * 将 Web 端桌面布局中第二栏宽度由 `w-72`（288px）拓宽至 `w-80`（320px），整体宽度增加约 11%；
  * 配合加宽后的列宽，标题与正文摘要容纳更多文字内容，整体排版更加舒展通透。
* **多端同步构建与持续交付**：
  * 同步更新全局构建属性配置 `Directory.Build.props`、Web 运行时版本 `version.js` 及 `package.json` 至 `2.2.1`；
  * 完成最新版本静态产物全量打包，并同步发布上线至 Firebase Hosting (`light-note.web.app`) 与 Cloudflare Pages (`light-note.pages.dev`)。

### V2.2.0 (2026-09-28)

**版本定位**
支持系统托盘常驻与极简右键菜单、开机静默启动到托盘与关闭最小化到托盘；彻底修复桌面端与 Web 端编辑器在跨段落及从后往前划选文字时选区被自动清空重置的底层事件冒泡缺陷；全面增强富文本阅读与排版体验，桌面原生版与 Web 端双端支持图片自由拖拽缩放、快捷预设与原图大图预览（Lightbox）、超链接阅读跳转（Ctrl+点击）及长文本防横向溢出，工具栏保持极简专注。

**主要修改**

* **系统托盘与常驻后台支持**：
  * 新增 `TrayIconService`，使用原生黄色图标常驻 Windows 系统托盘；
  * 支持鼠标左键单击或双击托盘图标秒级唤醒/激活主窗口；
  * 参考 SoftTrace、LinkFlow 规范定制右键托盘菜单：包含“打开 LightNote”、“开机自启动”（带实时读取勾选状态）、“退出”；
  * 引入 `SetForegroundWindow` 机制，确保右键托盘菜单在点击外部时即刻平滑失焦关闭；
  * 点击主窗口右上角关闭按钮 `[×]` 时自动最小化隐藏到托盘，后台静默保存数据；
  * 支持开机自启动携带 `--background` 参数，实现静默常驻后台托盘，随时待命。
* **文本划选选区保护与聚焦重构**：
  * 在 Web 端与桌面原生端编辑器中引入全局选区检测保护（`window.getSelection()?.isCollapsed`），划选释放鼠标时坚决不执行光标转移；
  * 移除对编辑容器根节点的暴力 `focus('end')`，仅在垂直点击落点确实处于全文末行下方时才聚焦末尾，彻底消除跨段落划选与段间外边距点击导致选区被冲掉的 Bug。
* **图片交互与尺寸缩放增强（桌面端与 Web 双端全面支持）**：
  * 桌面原生版（WebView2）与 Web 端图片节点重构为交互式组件，鼠标悬停或选中时右下角显示琥珀色调节手柄，支持鼠标自由拖拽等比缩放；
  * 浮动快捷操作栏提供 `25%`、`50%`、`75%`、`100%（原宽）` 一键快速缩放按钮；
  * 修复百分比缩放后选中外边框及右下角手柄未能贴合图片宽度的样式缺陷，确保外框尺寸与缩放后图片严格贴合；
  * 图片宽度属性加入 TipTap 持久化体系，尺寸随笔记内容与 SQLite 数据库持久同步；
  * 支持双击图片或点击放大镜按钮唤起带毛玻璃背景的沉浸式全屏原图预览模态框（Lightbox），支持 Esc 键极速退出。
* **笔记列表图片缩略图（类似印象笔记）**：
  * 卡片结构深度重构：缩略图严格占卡片前三行（标题 + 两行摘要）右侧（60×60 正方形，CornerRadius 6px），与正文行高精准齐平；第四行（时间与笔记本标签）贯通全宽，笔记本标签始终贴合卡片右侧边界，排版视觉绝对统一；
  * 图像严格居中裁剪：重构裁剪管道，按 `(orig - min) / 2` 严格提取中心正方形视域，彻底消除左偏缺陷；Web 端同步适配 `object-cover object-center`；
  * 本地磁盘持久化缓存与异步解码：本地新增 `%UserProfile%\.lightnote\cache\thumbnails\` 磁盘缓存，首度提取后自动保存 120×120 高清居中正方形图；冷启动直接从磁盘秒级命中，首次解码采用后台异步任务零阻塞 UI 线程；
  * 智能多图筛选策略：自动提取笔记正文第一张有效图片，并过滤小于 32px 的表情包或装饰小图标；云端未同步图标内嵌标题行，布局无任何冲突。
* **超链接体系与阅读跳转体验**：
  * 集成 `@tiptap/extension-link` 扩展，规范化 `<a>` 超链接的解析与渲染；
  * 兼顾编辑与阅读：日常点击定位输入光标，`Ctrl + 单击` 直接调用默认系统浏览器在新标签页打开目标链接；
  * 配置 `overflow-wrap: anywhere; word-break: break-word;`，防止超长无空格链接挤爆页面。
* **工具栏极简与状态实时反显**：
  * 工具栏保持极简专注，去除冗余的撤销/重做按钮，撤销/重做完全回归自然流畅的 `Ctrl+Z` / `Ctrl+Y` 全局快捷键；
  * Web 端监听 `onSelectionUpdate`，字体与字号下拉菜单随光标所在文字动态反显当前属性。
* **输入流转与排版细节打磨**：
  * 正文第一行行首按下 `Backspace` 或 `↑` 时平滑退回标题输入框末尾；
  * 代码块新增 `overflow-x: auto` 横向滑动条；
  * 公式节点移除 `select-none`，拖选文字穿过公式时选区连贯自然。
