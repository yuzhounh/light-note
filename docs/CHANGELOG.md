# LightNote 更新与开发日志 (Changelog)

### V2.2.0 (2026-09-28)

**版本定位**
支持系统托盘常驻与极简右键菜单、开机静默启动到托盘与关闭最小化到托盘；彻底修复编辑器在跨段落及从后往前划选文字时选区被自动清空重置的底层事件冒泡缺陷；全面增强富文本阅读与排版体验，支持图片自由拖拽缩放与原图大图预览（Lightbox）、超链接阅读跳转（Ctrl+点击）及长文本防横向溢出，新增工具栏撤销/重做按钮与随光标实时反显。

**主要修改**

* **系统托盘与常驻后台支持**：
  * 新增 `TrayIconService`，使用原生黄色图标常驻 Windows 系统托盘；
  * 支持鼠标左键单击或双击托盘图标秒级唤醒/激活主窗口；
  * 参考 SoftTrace、LinkFlow 规范定制右键托盘菜单：包含“打开 LightNote”、“开机自启动”（带实时读取勾选状态）、“退出”；
  * 引入 `SetForegroundWindow` 机制，确保右键托盘菜单在点击外部时即刻平滑失焦关闭；
  * 点击主窗口右上角关闭按钮 `[×]` 时自动最小化隐藏到托盘，后台静默保存数据；
  * 支持开机自启动携带 `--background` 参数，实现静默常驻后台托盘，随时待命。
* **文本划选选区保护与聚焦重构**：
  * 在 Web 端与桌面原生端编辑器中引入全局选区检测保护（`window.getSelection()?.isCollapsed`），划选释放鼠标时坚决不执行光标转移；
  * 移除对编辑容器根节点的暴力 `focus('end')`，仅在垂直点击落点确实处于全文末行下方时才聚焦末尾，彻底消除跨段落划选与段间外边距点击导致选区被冲掉的 Bug。
* **图片交互与尺寸缩放增强**：
  * 图片节点重构为交互式组件，鼠标悬停或选中时右下角显示琥珀色调节手柄，支持鼠标自由拖拽等比缩放；
  * 提供 `25%`、`50%`、`75%`、`100%（原宽）` 一键快速缩放按钮；
  * 图片宽度属性加入 TipTap 持久化体系，尺寸随笔记内容同步保存；
  * 支持双击图片或点击放大镜按钮唤起带毛玻璃背景的沉浸式全屏原图预览模态框（Lightbox）。
* **超链接体系与阅读跳转体验**：
  * 集成 `@tiptap/extension-link` 扩展，规范化 `<a>` 超链接的解析与渲染；
  * 兼顾编辑与阅读：日常点击定位输入光标，`Ctrl + 单击` 直接调用默认系统浏览器在新标签页打开目标链接；
  * 配置 `overflow-wrap: anywhere; word-break: break-word;`，防止超长无空格链接挤爆页面。
* **工具栏状态反显与快捷撤销/重做**：
  * 顶部工具栏增加“撤销（Ctrl+Z）”与“重做（Ctrl+Y）”按钮，支持禁用状态动态置灰；
  * 监听 `onSelectionUpdate`，字体与字号下拉菜单随光标所在文字动态反显当前属性。
* **输入流转与排版细节打磨**：
  * 正文第一行行首按下 `Backspace` 或 `↑` 时平滑退回标题输入框末尾；
  * 代码块新增 `overflow-x: auto` 横向滑动条；
  * 公式节点移除 `select-none`，拖选文字穿过公式时选区连贯自然。
