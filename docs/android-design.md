# Android 列表与交互设计

整理日期：2026-10-18。依据截至 2026-10-16 的实施记录；本次仅整理文档，没有重新构建或核验安装版本。原始方案、版本交付和测试记录见[历史审查与实施依据](../review/android_optimization.md)，发布状态见[发布记录](release_status.md)。

## 数据与列表

- 手机与电脑保留完整笔记文字，沿用全文同步和本地检索；列表分批渲染属于显示分页。
- 图片按查看需要下载，已下载图片保留本机缓存。此前正文按需下载、云端全文扫描和摘要补写草稿已撤回。
- Android 品牌行与笔记列表位于同一滚动容器；品牌行约 52px，自然滚出，第二行约 48px 的笔记本、数量及排序工具栏 sticky 吸顶。回到顶部自然恢复，无额外滚动方向状态机。
- 汉堡按钮在品牌行，采用 44px 圆形入口；系统状态栏、正文页和 Windows 原生界面沿用各自布局。
- 从正文返回列表时保留滚动位置、已显示卡片和顶栏状态；编辑笔记不重置列表分页。

## 卡片与浮动菜单

- 单栏、双栏和三栏网页布局均为日期时间左对齐、笔记本标签右对齐；长名称省略，日期不压缩，单笔记本视图隐藏重复名称。
- 网页右键与长按复用 Android 浮动菜单，靠近目标笔记定位，下方不足时向上显示，并限制在可见区域。菜单打开时锁定对应列表滚动，关闭后恢复。
- 操作行保持 56px；操作与字数、创建和编辑时间之间用细分隔线区分。保留轻遮罩与目标笔记高亮。
- 手机列表和长按菜单不提供删除入口；删除及确认保留在正文详情右上角。早期菜单含删除操作的描述属于历史方案。
- 点击外部、网页 Esc 或 Android 返回键关闭；关闭动作不传递给底层笔记，长按松手不执行操作。

## 返回栈与状态

- Android 返回按可见层级关闭设置、历史、公式、图片预览和菜单，再关闭侧栏、返回列表，最后退出；原生监听只注册一次。
- 图片占位/失败重试、同步状态区分、缓存管理和原生导出仍按原记录中的待办处理，不能仅因列入方案就视为完成。
- 原记录已报告 2.2.22 的统一发布与设备覆盖安装；历史日志中的 2.2.18、2.2.21 等不作为今天的实时版本检测。
